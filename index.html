ダウンロード前に必ず確認すること（偽アプリ対策）

メタマスクは人気が高い分、検索広告・偽アプリ・偽拡張機能が紛れやすいのが現実です。インストール前に次を徹底してください。

  • ストア内検索だけで判断しない：同名アプリが紛れることがあります。
  • 提供元（発行元）を確認する：拡張機能・アプリの詳細画面で、開発元名や配布元表記を必ずチェックします。
  • レビューの急増・不自然な日本語：短期間に高評価が集中している、同じ文面が多い場合は警戒します。
  • 権限の要求が過剰：不要に広い権限を求めるものは避けます。
  • シークレットリカバリーフレーズを求める画面：インストール直後に外部サイトへ誘導し、フレーズ入力を迫るものは危険です。

重要：シークレットリカバリーフレーズ（復元フレーズ）は、あなたのウォレットの「鍵そのもの」です。誰にも教えない、スクリーンショットで残さない、クラウドに保存しない、が基本です。

不安な場合は、まずセキュリティ最終チェックを読んでから作業を進めてください。

デスクトップ：拡張機能をインストールする

PCでは、ブラウザ拡張機能としてメタマスクを使うのが一般的です。作業の流れはどのブラウザでもほぼ同じで、「拡張機能ストアでMetaMaskを探し、追加し、初期設定へ進む」です。

Chrome / Brave / Edge（Chromium系）の場合

  1. ブラウザの拡張機能ストアを開き、「MetaMask」または「メタマスク」で検索します。
  2. 詳細ページで提供元（発行元）を確認します（似た名前の別物に注意）。
  3. 「追加」「インストール」などのボタンを押します。
  4. 追加後、ブラウザ右上の拡張機能一覧からメタマスクをピン留めすると、迷いにくくなります。
  5. メタマスクを開き、新規作成または復元に進みます。

Firefoxの場合

  1. アドオン（拡張機能）ページで「MetaMask」を検索します。
  2. 詳細ページで提供元や評価を確認し、追加します。
  3. ブラウザツールバーに表示されない場合は、アドオン管理から表示位置を調整します。
  4. メタマスクを開き、新規作成または復元に進みます。

デスクトップで失敗しやすいポイント

  • 偽のダウンロードページ：検索結果の上位でも広告枠に偽サイトが混じることがあります。拡張機能は基本的に「各ブラウザの公式ストア」経由が安全です。
  • 別の拡張機能と混同：ウォレット系の名称は似やすいので、アイコン・提供元・説明文を落ち着いて確認します。
  • 複数のウォレット拡張を同時に入れる：接続先サイトで誤って違うウォレットを開く原因になります。慣れるまでは必要最小限がおすすめです。

モバイル：アプリをインストールする

スマホでは公式アプリとしてメタマスクを利用します。モバイルは生体認証を併用できるため、運用しやすいのが利点です（ただし、復元フレーズの保管が最優先である点は変わりません）。

iPhone（iOS）の場合

  1. App Storeで「MetaMask」または「メタマスク」を検索します。
  2. 詳細ページで提供元表記を確認します（同名・類似名に注意）。
  3. 入手（インストール）し、起動します。
  4. 案内に沿って新規作成または復元を選びます。
  5. 可能なら、生体認証（Face ID / Touch ID）を有効化します。

Androidの場合

  1. Google Playで「MetaMask」または「メタマスク」を検索します。
  2. 詳細ページで提供元、レビュー、ダウンロード数などの整合性を確認します。
  3. インストールして起動し、新規作成または復元を選びます。
  4. 画面ロックや生体認証を設定し、端末側のセキュリティも強化します。

モバイルで失敗しやすいポイント

  • 似たアイコンの偽アプリ：インストール前に必ず提供元を確認します。
  • 復元フレーズをクリップボードに残す：コピー履歴から漏れるリスクがあります。入力後は履歴を消す意識が安全です。

新規ウォレット作成の流れ

初めてメタマスクを使う場合は、新規でウォレットを作成します。ここでの最重要ポイントはシークレットリカバリーフレーズの保管です。

  1. メタマスクで「新しいウォレットを作成」相当の選択肢を選びます。
  2. 利用規約などの案内を確認し、次へ進みます。
  3. 端末・ブラウザで使うパスワード（またはロック解除手段）を設定します。
  4. シークレットリカバリーフレーズを表示し、オフラインで控えます。
  5. 確認テスト（順番入力など）を完了させます。
  6. 初期画面に戻ったら、セキュリティ最終チェックを実施します。

保管のコツ：紙に書いて2部用意し、別々の安全な場所へ保管するのが現実的です。たとえば「自宅の耐火ケース」と「別の保管場所」のように分散します。

既存ウォレットの復元（引き継ぎ）

すでにウォレットを持っていて、別端末へ移行したい場合は「復元」を選びます。復元に必要なのは基本的にシークレットリカバリーフレーズです。

  1. メタマスク起動後、「ウォレットをインポート」「復元」などを選びます。
  2. シークレットリカバリーフレーズを入力します（例：（12語または24語のフレーズ））。
  3. 端末用のパスワードや生体認証を設定します。
  4. 残高やアカウントが表示されるか確認します。

復元後に残高が見えない場合は、まずネットワークや表示の問題を疑ってください。復元フレーズが正しければ、資産そのものが消えるわけではありません。

セキュリティ最終チェック

インストール直後に、このチェックを済ませるだけで事故率が大きく下がります。

  • 復元フレーズの保管：スクリーンショットなし、クラウド保存なし、第三者に共有しない。
  • 端末のロック：スマホは生体認証＋強いPIN、PCはログインパスワードと画面ロックを設定。
  • フィッシング対策：検索広告やDMのURLから入らない。怪しいページでフレーズ入力しない。
  • 権限の見直し：接続したサイト（DApps）を定期的に整理し、不要な接続は解除する。
  • 少額テスト：初回送金は小額で試し、手順が合っているか確認する。

慣れるまでは「急がない」「少額で試す」「確認してから進む」を合言葉にしてください。

よくあるトラブルと対処

拡張機能が表示されない

  • 拡張機能一覧（パズルアイコン等）からメタマスクを探し、ピン留めします。
  • 別プロファイルや別ブラウザに入れていないか確認します。

復元したのに残高が見えない

  • ネットワーク（チェーン）が想定どおりか確認します。
  • 同じ復元フレーズでも、表示しているアカウントが違うと残高が見えません。アカウントを切り替えて確認します。
  • トークンは自動表示されない場合があります。表示の追加が必要なケースがあります。

パスワードを忘れた

  • 端末・ブラウザのロック用パスワードは、基本的に復元フレーズがあれば再設定可能です。
  • 復元フレーズがない場合、取り戻せない可能性があります。日頃の保管が最重要です。

FAQ

メタマスクは無料でダウンロードできますか？

はい。メタマスクのダウンロード自体は無料です。ただし、ブロックチェーン上の取引にはネットワーク手数料（ガス代）が発生する場合があります。

スマホとPCで同じウォレットを使えますか？

可能です。どちらか一方で作ったウォレットを、もう一方で復元すれば同じウォレットとして利用できます（復元フレーズの管理に注意）。

復元フレーズはどこに保存するのが安全ですか？

基本はオフラインです。紙に書いて分散保管する、耐火ケースに入れるなどが現実的です。画像・クラウド・メモアプリは漏えい経路になりやすいので避けます。

「ウォレットを接続」しても大丈夫？

信頼できるサイトかどうかの確認が前提です。怪しいサイトに接続すると、承認操作を悪用される可能性があります。少しでも不安なら接続せず、セキュリティ最終チェックを優先してください。

注意：本記事は一般的な情報提供であり、投資助言ではありません。ウォレット運用は自己責任となるため、重要操作は必ず内容を確認してから実行してください。
